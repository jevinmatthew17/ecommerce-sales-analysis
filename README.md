## 🧰 Tools Used
- Python (pandas, numpy) — data generation & cleaning
- Google Colab — coding environment
- Google Looker Studio — dashboard & visualization

## 📁 Dataset
- **Source:** Synthetic E-Commerce dataset (Python generated)
- **Rows:** 5,000+ orders
- **Revenue:** $3.78M total transactions

## 🧹 What I Cleaned
- Removed duplicate rows
- Fixed missing category values
- Corrected data types (dates, numbers)
- Standardized column names
- Engineered revenue metrics
- Fixed date dimension errors using PARSE_DATE in Looker Studio

## 📈 Dashboard Insights
- 💰 Total Revenue: $3,780,000
- 📦 Total Orders: 5,000+
- 🏆 Top Categories: Electronics & Clothing
- ⭐ Avg Customer Rating: 3.06 / 5.0
